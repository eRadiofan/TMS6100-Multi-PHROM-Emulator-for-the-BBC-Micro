# Firmware

These are STM32CubeIDE version 2.x projects.

There are currently three projects defined, one for the STM32G031F8P6, one for the STM32G051F8P6 and most recently, one for the STM32C051F8P6. Code common to all projects is located in the Common folder.

Use File -> Import -> Import STM32 project -> STM32CubeMX project and choose the project suitable for your MCU.

The first 3 emulators produced were STM32G051F8P6 because that is what I had spare in my parts drawer. The next 30 produced were STM32G031F8P6 because they were the cheapest option at the time. Currently the STM32C051F8P6 seems to be more available and cost effective. Check with your supplier.
